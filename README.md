# Lab 1 : Initialisation et Gestion de MySQL

## Description
Ce projet contient la configuration initiale et les scripts SQL pour le Lab MySQL.

## Structure du projet
- `lab1_setup.sql`
- `utilisateur_dump.sql`
- `README.md`

## Notes personnelles
- Port par défaut : 3306
- Suppression de table : DROP TABLE nom_table;
- Arrêt du service : sudo systemctl stop mysql
- Sécurisation : mysql_secure_installation
- Gestion des utilisateurs : CREATE USER et GRANT
